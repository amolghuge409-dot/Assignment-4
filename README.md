# Assignment 4: Employee Registration Form

A responsive employee registration form built with HTML, CSS, and vanilla
JavaScript. It validates employee name, work email, password, phone number,
department, and confirmation before displaying a registration success message.

## Run locally

Open `index.html` in a modern browser. No package installation or build step is
required.

## GitHub Pages

The form is a front-end demo. A successful submission is shown in the browser;
the employee details are not sent to a server or saved to a database.
